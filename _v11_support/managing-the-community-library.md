# Community Library Management

The Materia Community Library is built on contributions from your users. Understandably, this necessitates a number of administrative and moderation tools to manage Community Library listings, manage tags, review reports, and issue bans.

Library management is primarily performed from the Library Admin panel in the Support drop-down menu. This panel is split into three sub-menus:

1. **Tag Management**. The full list of user-defined tags is provided here. You can rename or remove individual tags as necessary.
2. **Entry Management**. This is the primary administrative UI. All Library entries are populated here by default; use the drop-down to filter by specific circumstances, such as Featured entries, Reported entries, or Banned entries. Selecting an entry will take you to the instance administration panel, which includes Community Library-related tools at the bottom.
3. **Category Management**. Materia ships with a series of default categories (or disciplines) based on course and subject offerings at UCF. You can eliminate, rename, or remove categories from this administration panel. Each category is associated with a color and an optional banner graphic.

## Library-related Actions in User and Instance Management

Both the User and Instance administration panels include Community Library-related operations.

When selecting a widget instance, the Community Library section will populate if the entry has been published to the Library. This section will include information about the Library listing, including:

- **Status**: Indicates the share status of the widget (Shared or Unpublished)
- **Reports**: The report count the entry has accumulated, and the types of each report.
- **Copies**: The number of derivative copies created from the library entry.
- **Likes**: The number of times instructors have "liked" (Recommended) the widget.
- **Featured**: Determines whether the widget will be included in the Featured section at the top of the Community Library.
- **Ban**: Bans (or unbans) the widget from the Library. Note that banned widgets are automatically unlisted.

In the user administration panel, a Community Library section will detail the user's library status. **In Good Standing** means their entries have not been reported. Otherwise, the report count will be displayed. You can also choose to ban the user from the Community Library completely (or revoke an existing ban). Note that banning a user will automatically **delist all of their previously published widgets**. This operation is not symmetric: revoking a ban will not republish them.

## Managing the Featured section

The Community Library includes a **Featured** section prominently displayed at the top of the landing page. This gives your institution an opportunity to highlight particularly noteworthy widgets that have been shared to the library. You can quickly review featured widgets by filtering by "Featured" in the library entries administration panel, and feature/unfeature individual widget instances through the checkbox in the instance admin panel.

The Featured section can include custom text and a banner. These are managed through the **Site Administration** panel, which is only accessible to super users. Images uploaded as "Library Banner" will be used instead of the default Featured banner. Messages uploaded under **Library Header** and **Library Text** will replace the default text for the featured section.
